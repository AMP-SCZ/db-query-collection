# 07. ORM To SQL Cheatsheet

This page maps common Django ORM patterns in this repository to rough SQL equivalents.

Use this as a translation aid for DBeaver and SQL review. SQL shown here is conceptual and may differ from exact SQL generated by Django for your database backend.

## 1) Basic Selection

Django ORM:

```python
qs = MriZip.objects.filter(
    most_recent_file=True,
    marked_to_ignore=False,
    qqc__manual_check_done=True,
    qqc__curated=True,
).exclude(
    qqc__qqc_rescans__isnull=False,
).exclude(
    mri_run_sheet__timepoint__isnull=True,
)
```

Approximate SQL:

```sql
SELECT mz.*
FROM qqc_web_mrizip mz
JOIN qqc_web_qqc q ON q.mri_zip_id = mz.id
LEFT JOIN qqc_web_mrirunsheet rs ON rs.id = mz.mri_run_sheet_id
WHERE mz.most_recent_file = TRUE
  AND mz.marked_to_ignore = FALSE
  AND q.manual_check_done = TRUE
  AND q.curated = TRUE
  AND NOT EXISTS (
    SELECT 1
    FROM qqc_web_qqcrescan_qqc_rescan qr
    WHERE qr.qqc_id = q.id
      AND qr.qqcrescan_id IS NOT NULL
  )
  AND rs.timepoint IS NOT NULL;
```

## 2) values_list + distinct

Django ORM:

```python
subject_ids = qs.values_list("subject_id", flat=True).distinct().order_by("subject_id")
```

Approximate SQL:

```sql
SELECT DISTINCT subject_id
FROM (...base query...) t
ORDER BY subject_id;
```

## 3) select_related (FK join)

Django ORM:

```python
Apply.objects.select_related(
    "template__reference__artificial_site",
    "artificial_site",
)
```

Approximate SQL:

```sql
SELECT a.*, t.*, r.*, ars_ref.*, ars_apply.*
FROM dmriharm_apply a
LEFT JOIN dmriharm_template t ON t.id = a.template_id
LEFT JOIN dmriharm_reference r ON r.id = t.reference_id
LEFT JOIN dmriharm_artificial_site ars_ref ON ars_ref.id = r.artificial_site_id
LEFT JOIN dmriharm_artificial_site ars_apply ON ars_apply.id = a.artificial_site_id;
```

## 4) prefetch_related (separate query strategy)

Django ORM:

```python
Template.objects.prefetch_related("target_sites")
```

Approximate SQL strategy:

```sql
-- Query 1: templates
SELECT * FROM dmriharm_template;

-- Query 2: all related target sites for returned template ids
SELECT ts.template_id, s.*
FROM dmriharm_template_target_sites ts
JOIN dmriharm_artificial_site s ON s.id = ts.artificialsite_id
WHERE ts.template_id IN (...template ids from query 1...);
```

## 5) Grouped Count (values + annotate Count)

Django ORM:

```python
rows = queryset.values("status").annotate(count=Count("id"))
```

Approximate SQL:

```sql
SELECT status, COUNT(id) AS count
FROM dmriharm_template
GROUP BY status;
```

## 6) Conditional Count with filter=Q(...)

Django ORM:

```python
ArtificialSite.objects.annotate(
    hc_unique_subjects=Count(
        "qqcs__subject_id",
        filter=Q(qqcs__subject__basicinfo__cohort__iexact="HC"),
        distinct=True,
    )
)
```

Approximate SQL (PostgreSQL style):

```sql
SELECT s.id,
       COUNT(DISTINCT q.subject_id)
         FILTER (WHERE LOWER(b.cohort) = 'hc') AS hc_unique_subjects
FROM dmriharm_artificial_site s
LEFT JOIN dmriharm_artificial_site_qqcs aq ON aq.artificialsite_id = s.id
LEFT JOIN qqc_web_qqc q ON q.id = aq.qqc_id
LEFT JOIN qqc_web_subject subj ON subj.id = q.subject_id
LEFT JOIN qqc_web_basicinfo b ON b.subject_id = subj.id
GROUP BY s.id;
```

## 7) Q composition (AND/OR)

Django ORM:

```python
finished = (Q(status="completed") | Q(completed=True)) & Q(failed=False)
Apply.objects.filter(finished)
```

Approximate SQL:

```sql
SELECT *
FROM dmriharm_apply
WHERE (status = 'completed' OR completed = TRUE)
  AND failed = FALSE;
```

## 9) Subquery for safe parent filtering

Django ORM:

```python
valid_dwi_qqc_ids = (
    Series.objects.filter(...)
    .exclude(series_description__icontains="sbref")
    .values("qqc_id")
    .distinct()
)

qs = MriZip.objects.filter(qqc__in=Subquery(valid_dwi_qqc_ids))
```

Approximate SQL:

```sql
SELECT mz.*
FROM qqc_web_mrizip mz
WHERE mz.qqc_id IN (
  SELECT DISTINCT s.qqc_id
  FROM qqc_web_series s
  WHERE ...
    AND s.series_description NOT ILIKE '%sbref%'
);
```

## 10) OuterRef + Subquery (latest related row)

Django ORM:

```python
latest_series_subquery = series_qs.filter(
    series_number=OuterRef("series_number"),
    series_description=OuterRef("series_description"),
).order_by("-first_dicom_modified").values("id")[:1]

series_qs = series_qs.filter(id__in=Subquery(latest_series_subquery))
```

Approximate SQL (window-function equivalent):

```sql
WITH ranked AS (
  SELECT s.*,
         ROW_NUMBER() OVER (
           PARTITION BY s.series_number, s.series_description
           ORDER BY s.first_dicom_modified DESC
         ) AS rn
  FROM qqc_web_series s
  WHERE ...
)
SELECT *
FROM ranked
WHERE rn = 1;
```

## 11) Exists annotation

Django ORM:

```python
qs = qs.annotate(has_t1w=Exists(t1w_subquery))
```

Approximate SQL:

```sql
SELECT t.*,
       EXISTS (
         SELECT 1
         FROM ... t1w
         WHERE t1w.parent_id = t.id
       ) AS has_t1w
FROM ... t;
```

## Practical Notes For Analysts

- Django may emit extra joins for ordering, filtering, and related fields.
- prefetch_related does not become one SQL query; it is usually multiple queries.
- distinct(field) behavior is PostgreSQL-specific and often maps to DISTINCT ON semantics.
- For exact generated SQL, inspect queryset.query in a Django shell or use query logging.
